## Usability Issues

### Zero-Results Dead Ends  `HIGH`

14% of on-site searches return nothing, and the empty state offers no recovery path.

> **Recommendation:** Add spell-tolerant matching, category suggestions and top sellers to the zero-results state.

### Facet Overload on Mobile  `MEDIUM`

Twenty-two filter facets render in a full-screen drawer; users lose their result context.

> **Recommendation:** Prioritise five high-usage facets per category and collapse the long tail behind "More filters".

### Mega-Menu Hover Traps  `MEDIUM`

Diagonal cursor paths close the desktop mega-menu before users reach second-level items.

> **Recommendation:** Add hover intent tolerance and make top-level categories clickable landing pages.

## Research Insights

### Search Users Convert Double  `behavioral`

Sessions that use search convert at 4.9% vs 2.4% for browse-only — improving search has outsized revenue leverage.

### Category Names Fail the Tree Test  `usability`

"Lifestyle" and "Essentials" scored under 35% success; participants expected concrete nouns like "Home" and "Beauty".

### Autocomplete With Products  `opportunity`

Prototype autocomplete showing product thumbnails cut time-to-first-result by half in testing.

### Keyboard Trap in Filter Drawer  `accessibility`

Focus never returns to the trigger button when the drawer closes; tab order restarts at the page top.
